# Video Mirror Flip

Скрипт для отзеркаливания видео на любых сайтах по нажатию Alt + M.

## Установка
1. Установите расширение [Tampermonkey](https://tampermonkey.net).
2. Нажмите на кнопку ниже для автоматической установки скрипта:

[![Установить](https://shields.io)](chrome-extension://dhdgffkkebhmkfjojejmpbldmpobfkfo/ask.html?aid=7a1f9765-7c29-425a-96b9-62f770a88f23)
