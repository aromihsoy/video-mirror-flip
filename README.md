# Video Mirror Flip

Скрипт для отзеркаливания видео на любых сайтах по нажатию Alt + M.

## Установка
1. Установите расширение [Tampermonkey](https://tampermonkey.net).
2. Нажмите на кнопку ниже для автоматической установки скрипта:

[![Установить](https://img.shields.io/badge/install-userscript-brightgreen)](https://raw.githubusercontent.com/aromihsoy/video-mirror-flip/main/video-mirror-flip.user.js)
